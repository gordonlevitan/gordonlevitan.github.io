# Daniel Gordon-Levitan — Pixel Arcade Jekyll site

This is a complete, single-page Jekyll website for GitHub Pages. The pixel-art portrait is **embedded directly inside `index.html`** as a base64 PNG data URI. No separate photo upload is needed.

## Publish
1. Open https://github.com/gordonlevitan/gordonlevitan.github.io
2. Upload the contents of this ZIP **after extracting** to the repository root. Replace `index.html` and `_config.yml` when prompted.
3. Commit the changes.
4. In Settings → Pages, choose Deploy from a branch → `main` → `/ (root)` (or retain your existing working Pages deployment).
5. Wait for the GitHub Pages deployment to finish and visit https://gordonlevitan.github.io/ . Hard-refresh if needed.

The website includes inline pixel-molecule SVG art, pixel text, and the CHEMISTRY WOW! banner, with no image dependencies.
